# beebaa — Tic-Tac-Toe

A tic-tac-toe web app built with React, Vite, and TypeScript. Play two-player
hot-seat on one keyboard, or face an unbeatable minimax computer opponent —
every game against it ends in a computer win or a draw. A persistent
scoreboard (backed by `localStorage`) tracks X wins, O wins, and draws across
reloads, with a one-click reset.

## Prerequisites

- Node.js 20+

## Commands

```sh
npm install        # install dependencies
npm run dev        # start the dev server
npm test           # run the test suite (vitest)
npm run typecheck  # type-check all projects (tsc -b)
npm run build      # type-check and produce a production build in dist/
npm run preview    # serve the production build locally
```
